A session, start to finish

{% icon "expand" %}
  1. Get the educator kit. Instructions for your AI assistant, the format and the tools, and no course content: {{ kit }}. Clone it once; run git pull in it before each session.
  2. Start from what the site has. Download the course files, above, and in the kit run uv run tools/unpack.py {{ course.slug }}.zip. It puts the course in courses/{{ course.slug }}/ and bookmarks it with a commit in your own copy (nothing is uploaded by that): your starting point.
  3. Add the material. Lecture slides, labs and past papers go in courses/{{ course.slug }}/source/. They stay on your computer and are never packed or uploaded. Important: material from an earlier year goes in a folder named after that year, source/2025-26/, never mixed in with this year's, so that it is written up as that year's and not as this one's.
  4. Let your assistant write. Open the kit's folder in your AI assistant and give it this: 
    Update the CMS for this course: {{ course.slug }}
  5. Check, pack, hand in. Read what it wrote against the lecture; git diff shows every line that changed. Then uv run tools/pack.py {{ course.slug }}, and hand in the zip it makes.
