How to add to it

  1. Get the educator kit. It holds the instructions for your AI assistant, the format and a checker, and no course content: {{ kit }}. Clone it once. Before each session run git pull in it for the latest instructions; that never touches your course.
  2. Put your course into it. Download the course files and unpack the zip into the kit's courses/ folder, so that you have courses/{{ course.slug }}/course.yaml. Git ignores that folder.
  3. Add the material. Put the lecture slides, labs and past papers in courses/{{ course.slug }}/source/. They stay on your computer and are never packed or uploaded.
  4. Let your assistant write. Open the kit's folder in your AI assistant and give it this: 
    Update the CMS for this course: {{ course.slug }}
  5. Check, pack, hand in. Read what it wrote against the lecture. Then run uv run tools/pack.py {{ course.slug }} and hand in the zip it makes. It is on the site once it has been taken in and published. The kit's README has all of this in full.

What it takes

The work. For each lecture: notes that can be read in one sitting, flashcards, and where the course has them, problems and past papers with worked answers. All of it is plain text files in a fixed format, kept in a shared repository.

The tools. It can be done by hand or with a free chatbot. For a whole course, what works is a paid AI assistant that reads the slides and writes the files, with you checking every lecture against the original.

What you get. The course you know best, in a form your whole year can study from, and requests about it come to you.
